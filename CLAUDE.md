# Halif Media website

Single-page static site (index.html, styles.css, app.js). No build step. Hosted on GitHub Pages at halifmedia.com.

## Brand
- Colours: Charcoal #28282A, Warm Cream #FBFAF8, Greige #E4E1DC, Dark Burgundy #7A3B4E. Use no others.
- Fonts: Unbounded 700 for headings, Source Sans 3 for body.
- Style: editorial, restrained, lots of whitespace. No stock photos, stats, testimonials, carousels or filler sections.

## Copy
- Describe the agency as a "creator marketing agency", never "influencer".
- Plain, direct tone. Short sentences. No hype, no em dashes.
- Every claim must be true. No invented results, clients or roster size.
- No music, women or gambling imagery anywhere.

## Never change without being asked
- CNAME file.
- GOOGLE_SCRIPT_URL in app.js.
- The contact form fields (name, email, message).
- Mobile menu must match the desktop nav links exactly.

## Workflow
- Work on a branch. Never push to main. Describe what changed and stop.
